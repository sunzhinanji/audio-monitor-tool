================================================================================
                    音频监控工具 - 环境配置说明
================================================================================


一、系统要求

- 操作系统：Windows 10 / Windows 11（64位）
- 权限要求：建议以管理员身份运行（可获取更完整的音频进程检测结果）
- 网络要求：仅首次安装依赖时需要联网


二、需要的环境与依赖库

2.1 Python 运行环境

本工具基于 Python 开发，需要先安装 Python 解释器。

版本要求：Python 3.8 或更高版本（推荐 Python 3.12.x）

下载地址：https://www.python.org/downloads/

安装注意事项：
- 安装时务必勾选 "Add Python to PATH"
- 安装完成后建议重启电脑，确保环境变量生效


2.2 Python 依赖库

以下是本工具运行所需的第三方库：

┌─────────────────┬────────────┬──────────────────────────────────────┐
│ 库名称          │ 版本要求   │ 用途说明                            │
├─────────────────┼────────────┼──────────────────────────────────────┤
│ PySide6         │ >= 6.5.0   │ Qt GUI 框架，提供界面和交互功能      │
│ psutil          │ >= 5.9.0   │ 进程管理，获取进程信息和可执行文件路径 │
│ pywin32         │ >= 306     │ Windows API 调用，用于底层操作        │
│ numpy           │ >= 1.24.0  │ 音频数据处理（仅 1.2 版本需要，可忽略）│
│ sounddevice     │ >= 0.4.5   │ 音频捕获（仅 1.2 版本需要，可忽略）   │
└─────────────────┴────────────┴──────────────────────────────────────┘


2.3 .NET 运行环境（仅 1.3+ 版本需要）

1.3 及以上版本通过 C# 程序（AudioMeterCOM.exe）获取音频会话和音量信息。
该程序基于 .NET 8.0 开发，需要安装 .NET 运行时。

版本要求：.NET 8.0 SDK 或 Runtime

下载地址：https://dotnet.microsoft.com/download/dotnet/8.0

提示：如果不需要音量检测功能，可以删除 AudioMeterCOM 目录，
      工具会自动回退到内核句柄检测模式。


2.4 C++ 运行库（可选）

某些情况下可能需要 Visual C++ Redistributable：
- 下载地址：https://aka.ms/vs/17/release/vc_redist.x64.exe


三、一键安装方法（推荐）

3.1 双击运行 "依赖安装.bat"

该批处理脚本会自动完成以下操作：
1. 检查 Python 是否已安装
2. 检查并升级 pip
3. 安装所有必需的 Python 库
4. 验证安装是否成功
5. 提示运行程序


3.2 手动安装方法（备选）

如果自动安装失败，可以打开命令提示符（CMD）依次执行：

pip install --upgrade pip
pip install PySide6 psutil pywin32

如果使用 1.2 版本：
pip install numpy sounddevice


四、验证环境

安装完成后，可以通过以下命令验证：

python --version                     # 检查 Python 版本
pip list | findstr PySide6           # 检查 PySide6 是否安装
pip list | findstr psutil            # 检查 psutil 是否安装


五、运行程序

所有环境配置完成后，直接双击 .pyw 文件即可运行程序。

如果双击无反应，请尝试：
- 右键文件 -> 打开方式 -> 选择 pythonw.exe
- 或在 CMD 中执行：pythonw 程序名.pyw


六、常见问题

Q1：双击 .pyw 文件没有反应？
A1：确保 Python 已正确安装并关联 .pyw 文件扩展名。
    可以右键文件 -> 打开方式 -> 选择 pythonw.exe。

Q2：提示 "ModuleNotFoundError: No module named 'PySide6'"？
A2：运行 pip install PySide6 安装缺失的库。

Q3：检测不到音频进程？
A3：右键选择 "以管理员身份运行"。
    如果仍然不行，检查 AudioMeterCOM.exe 是否存在。

Q4：提示 "找不到 AudioMeterCOM.exe"？
A4：确保 AudioMeterCOM\publish\AudioMeterCOM.exe 文件存在。
    如果使用旧版本（1.1及以下），该提示可以忽略。

Q5：运行 Program.exe 提示 .NET 相关错误？
A5：需要安装 .NET 8.0 运行时。
    下载地址：https://dotnet.microsoft.com/download/dotnet/8.0
